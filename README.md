A focused content system for building portfolio authority around web content technology, CMS operations, frontend implementation, SEO/QA, localization, and AI-assisted workflows.

## Purpose

This repo helps turn professional experience into publishable portfolio content. Each blog post should support one or more target roles:

- Web Content & Marketing Technologist
- AEM / CMS Web Engineer
- Marketing Web Developer
- Web Producer
- Web Operations Specialist
- Frontend / UI Engineer
- Content Operations Technologist

# Career Blog Roadmap

Career blogs are stored separately from the main 10-blog topical roadmap. These posts explain the story behind the work: how my roles shaped my interests, how I developed into this space, and where I want to keep growing.

| Order | Blog | Status | Folder |
|---:|---|---|---|
| C01 | How I Found My Path in Web Content & Marketing Technology | Drafting | `08-career-blogs/blog-01-career-path-web-content-marketing-technology/` |

## Career Blog Purpose

Career blogs help recruiters, hiring managers, and collaborators understand:

- how my interest in content management development grew
- how my roles shaped my current direction
- why I connect frontend development, CMS operations, marketing technology, and workflow systems
- what kind of work I want to keep building toward

## Recommended Workflow

1. Start with `00-strategy/content-roadmap.md` for the main topical roadmap.
2. Draft each topical post inside `01-blog-drafts/`.
3. Draft career-positioning posts inside `08-career-blogs/`.
4. Create a LinkedIn version inside the relevant folder or `03-linkedin-posts/`.
5. Convert strongest posts into featured assets inside `04-featured-assets/`.
6. Track publishing progress in `07-publishing/publishing-tracker.md`.

## Folder Map

```text
00-strategy/        Positioning, roadmap, keyword map, target readers
01-blog-drafts/    Main 10-blog roadmap drafts, outlines, final posts
02-case-studies/   Portfolio case studies connected to the blog roadmap
03-linkedin-posts/ Short posts adapted from the blog content
04-featured-assets Resume brief, skills matrix, featured item copy
05-research-notes/ Notes, examples, source ideas, glossary
06-templates/      Reusable writing templates
07-publishing/     Calendar, tracker, QA checklist
08-career-blogs/   Career path, professional story, and positioning blogs
assets/            Images, diagrams, PDFs, downloads
```

## Definition of Done for Each Blog

- One strong framework, checklist, or journey arc

- Portfolio CTA added

- Practical lessons from each stage

- Related case studies linked
- LinkedIn post drafted
- Portfolio CTA added
