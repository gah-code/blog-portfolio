# 10-Blog Portfolio Roadmap

A focused content system for building portfolio authority around web content technology, CMS operations, frontend implementation, SEO/QA, localization, and AI-assisted workflows.

## Purpose

This repo helps turn professional experience into publishable portfolio content. Each blog post should support one or more target roles:

- Web Content & Marketing Technologist
- AEM / CMS Web Engineer
- Marketing Web Developer
- Web Producer
- Web Operations Specialist
- Frontend / UI Engineer
- Content Operations Technologist

## Content Pillars

| Pillar | What It Proves |
|---|---|
| CMS & Web Operations | AEM/CMS workflow thinking, migration support, publishing systems |
| Frontend + CMS | Ability to connect UI implementation with structured content |
| SEO, QA & Launch Readiness | Production discipline and launch-quality thinking |
| AI Workflow Systems | Practical use of AI for documentation, reporting, and operations |
| Career Authority | Clear professional positioning and communication |

## Recommended Workflow

1. Start with `00-strategy/content-roadmap.md`.
2. Draft each post inside `01-blog-drafts/`.
3. Create a LinkedIn version inside `03-linkedin-posts/`.
4. Convert strongest posts into featured assets inside `04-featured-assets/`.
5. Track publishing progress in `07-publishing/publishing-tracker.md`.

## Folder Map

```text
00-strategy/        Positioning, roadmap, keyword map, target readers
01-blog-drafts/    Blog drafts, outlines, final posts
02-case-studies/   Portfolio case studies connected to the blog roadmap
03-linkedin-posts/ Short posts adapted from the blog content
04-featured-assets Resume brief, skills matrix, featured item copy
05-research-notes/ Notes, examples, source ideas, glossary
06-templates/      Reusable writing templates
07-publishing/     Calendar, tracker, QA checklist
assets/            Images, diagrams, PDFs, downloads
```

## Definition of Done for Each Blog

- Clear target reader
- One practical problem
- One strong framework or checklist
- One generalized example
- One final takeaway
- SEO title and meta description drafted
- LinkedIn post drafted
- Portfolio CTA added
