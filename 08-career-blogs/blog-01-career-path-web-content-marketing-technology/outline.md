# Outline — How I Found My Path in Web Content & Marketing Technology

## Opening Hook — The Work Behind the Page

Open with the idea that marketing websites look simple from the outside, but behind every clean page is a system of content, design, code, QA, SEO, localization, and publishing decisions.

**Key point:** My career path has been about moving closer to the systems behind digital experiences.

## Creative Foundation — Learning to Care About Presentation

Explain how creative media taught me to care about:

- visual communication
- audience attention
- layout
- storytelling
- detail
- presentation quality
- how people experience content

**Transition:** Over time, I became less interested in only the final image or final page, and more interested in the structure that made the experience possible.

## Digital NEST — Building the Technical Foundation

Explain how Digital NEST introduced me to:

- HTML
- CSS
- JavaScript
- React
- Next.js
- UX/design
- CMS workflows
- full-stack foundations
- client/project delivery

**Key lesson:** Web development is not only about writing code. It is about building usable systems that people can understand, maintain, and improve.

## Robert Half — Entering Enterprise CMS and Marketing Web Work

Explain how Robert Half moved me into:

- marketing web development
- Drupal-to-AEM migration
- content operations
- multi-country web work
- QA/UAT
- SEO review
- redirect validation
- accessibility checks
- stakeholder coordination
- workflow improvement

**Key lesson:** CMS work is not simple publishing. It is operational infrastructure.

## Workflow Improvement — Discovering the Value of Systems Thinking

Explain my interest in:

- reducing duplicate work
- improving tracking
- creating cleaner handoffs
- standardizing workflows
- making status visible
- improving team delivery

**Key lesson:** A better system does not just make one task easier. It makes the next ten tasks clearer.

## WHOI — Strengthening Frontend Debugging and Technical Inspection

Explain how frontend debugging sharpened my technical inspection skills:

- JavaScript debugging
- Chrome DevTools
- browser APIs
- frontend behavior
- cross-browser stability
- UI consistency
- performance troubleshooting

**Key lesson:** Frontend knowledge helped me become a better CMS and web operations professional because it gave me a sharper eye for how content becomes experience.

## Hogarth / WWP at Apple — Seeing Content Operations at Global Scale

Explain how global content operations deepened my understanding of:

- AEM migration tasks

- ticket lifecycle reporting
- documentation workflows

**Key lesson:** Web content operations is a discipline of precision: the quiet work of making complex digital systems feel simple, consistent, and ready.

## AI-Assisted Workflows — A New Area of Interest

AI can support:

- documentation
- ticket summaries
- reporting

- workflow visibility

- clearer handoffs

Reflect on the layers:

This is the work I want to keep building toward: cleaner CMS workflows, stronger web operations, better launch systems, thoughtful frontend implementation, and practical AI-assisted processes that help teams work with more clarity.
