# Blog QA Checklist

Before publishing each post:

- [ ] Title is clear and recruiter-friendly
- [ ] Opening problem is specific
- [ ] Target reader can recognize the pain
- [ ] Post includes a practical framework
- [ ] Example is generalized and non-confidential
- [ ] No company-sensitive details are included
- [ ] One clear takeaway exists
- [ ] SEO title is written
- [ ] Meta description is written
- [ ] LinkedIn post is drafted
- [ ] Portfolio CTA is added
- [ ] Internal link to related case study or blog is added
